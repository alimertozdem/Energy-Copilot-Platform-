# STOP — this folder is the answer key

Everything in `practice-project/` is a **finished reference implementation**. Reading it before you have written your own version is how you end up able to *run* a pipeline but not *build* one.

**Go to `../sql-lab/` instead.** That folder has the raw dirty data and nothing else. You write every line yourself there.

Come back here only when:
- you have finished the same layer yourself, and want to compare, or
- a problem has genuinely beaten you for 20+ minutes.
