## How to add one (same on Upwork & freelancermap)

1. Portfolio → **Add a project / Hinzufügen**.
2. **Project title** → paste the *Title* line.
3. **Description** → paste the *Description* block.
4. **Skills / tags** → add the *Skills* line.
5. **Upload** the matching file — format depends on the platform:
   - **Upwork** → the **PDF** (max **5 PDFs** per project).
   - **freelancermap → Portfolio** → the **PNG**. This section accepts **.jpg / .png only,
     max 4 MB** (PDF is rejected with "Datei konnte nicht hochgeladen werden"). Up to 12
     images. *(A PDF CV/certificate goes under a different section, "Profilanlagen".)*
   - **Malt** → PNG (already done).
6. Save (Upwork: *Save as draft* first, then *Publish*).
